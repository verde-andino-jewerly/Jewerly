# Vuelta de prueba — Verde Andino Jewelry

Recorrido completo de la tienda, tal como lo haría un cliente y como lo
harías tú desde el panel. No hace falta saber nada de programación: todo se
hace con el navegador, el panel y la aplicación de Bold.

**Cómo usar este documento:** ve marcando cada paso con ✅ si salió como
dice, o ❌ si no. Al final de cada bloque hay un espacio para tus
comentarios y la lista de capturas que necesito. Guarda las capturas con el
número del bloque en el nombre (por ejemplo `bloque-5-1.png`).

**Tiempo:** entre 45 minutos y una hora.
**Costo:** una compra real con el precio más bajo que acepte Bold. Se
devuelve en el bloque 8, aunque la comisión de la pasarela puede quedarse.

---

## Antes de empezar

Ten a la mano:

- El computador y el celular.
- El panel abierto, con tu clave.
- La aplicación o la página de Bold donde ves tus ventas.
- Una tarjeta tuya para la compra de prueba.
- Tu correo abierto.

**Consejo:** abre la tienda siempre en una **ventana de incógnito**
(en Chrome: los tres puntos arriba a la derecha → "Nueva ventana de
incógnito"). Así ves la tienda como la ve un cliente nuevo, sin que se
mezcle con lo que ya habías mirado.

## Bloque 1 — La tienda vista por un cliente

Entra a **verdeandino.app** en una ventana de incógnito, en el computador.

| # | Qué hago | Qué debe pasar | ✅ / ❌ |
|---|---|---|---|
| 1.1 | Abro la tienda | Cargan las joyas con foto y precio | |
| 1.2 | Busco "prueba" en el buscador | Quedan solo las joyas de prueba | |
| 1.3 | Miro la joya `PRUEBA - no comprar` | Tiene una etiqueta verde que dice **"Última pieza disponible"** | |
| 1.4 | Borro lo que escribí en el buscador | Vuelven todas las joyas | |
| 1.5 | Hago clic en las pastillas de categoría de arriba (Anillos, Aretes, etc.) | El catálogo cambia según la categoría | |
| 1.6 | Abro los filtros y muevo el rango de precio | Quedan solo las joyas en ese rango | |
| 1.7 | En los filtros pruebo metal, piedra y "solo ofertas" | Cada uno cambia lo que se ve | |
| 1.8 | Le doy a "Limpiar filtros" | Vuelve el catálogo completo | |
| 1.9 | Hago clic en una joya | Se abre su ficha, con las fotos, la descripción y el precio | |
| 1.10 | Le doy a las flechas de las fotos | Pasan las fotos de esa joya | |

## Bloque 8 — Que no se venda dos veces la misma joya

Esta es la prueba más importante de todas.

**Primera parte** — la joya que compraste debe desaparecer sola:

| # | Qué hago | Qué debe pasar | ✅ / ❌ |
|---|---|---|---|
| 8.1 | Abro la tienda en una ventana de incógnito **nueva** | Carga | |
| 8.2 | Busco "prueba" | La joya `PRUEBA - no comprar` **ya no aparece** | |

**Segunda parte** — dos clientes comprando al mismo tiempo. Vas a hacer de
los dos clientes: uno en el computador y otro en el celular.

| # | Qué hago | Qué debe pasar | ✅ / ❌ |
|---|---|---|---|
| 8.3 | En el **computador**, agrego `PRUEBA 2 - no comprar` al carrito y llego hasta la pantalla de datos. **No confirmo todavía** | Estoy listo para confirmar | |
| 8.4 | En el **celular**, hago lo mismo con la misma joya. **Tampoco confirmo** | Estoy listo para confirmar | |
| 8.5 | Confirmo en el **computador** | Se abre la pantalla de pago de Bold. **No pago**, solo miro que haya abierto | |
| 8.6 | Cierro el pago en el computador sin pagar | — | |
| 8.7 | Ahora confirmo en el **celular** | Sale un **mensaje de error** diciendo que la joya ya está reservada o vendida, y **no** abre el pago | |

> El paso **8.7** es el que importa. Si en el celular también abriera el
> pago, significaría que dos clientes pueden pagar la misma joya única, y
> tú quedarías vendiendo algo que ya no tienes.

2. La pantalla de pago abierta en el computador (paso 8.5).
