# Prerender por pieza

Archivos generados automáticamente por `scripts/generar-prerender.mjs`.
Cada `<id>.html` es una página estática con OG completo para que
WhatsApp/Facebook/Twitter muestren preview correcto al compartir.
Un humano al abrirla es redirigido a `/?p=<id>` (deep-link cliente).

**No editar a mano** — se sobrescribe en cada corrida del workflow.
